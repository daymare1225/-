# 몬스터 ASMR 동반 게임

PC에서 몬스터를 수집·육성·교배하고, 모바일에서는 나만의 몬스터를 위젯과 생활형 콘텐츠로 만나는 오프라인 중심 동반 게임입니다. 몬스터마다 고유한 ASMR 사운드를 갖고 있어, 사용자는 밤에도 자신이 기른 몬스터와 함께 편안한 소리를 들을 수 있습니다.

> 이 문서는 현재의 기획과 기술 방향을 기록합니다. 모바일 앱의 플랫폼과 일부 게임 규칙은 아직 확정 전입니다.

## 핵심 경험

- **PC 수집과 방치 성장**: 입력에 반응하는 데스크톱 펫 경험을 바탕으로 몬스터를 발견하고, 방치 보상과 돌봄으로 성장시킵니다.
- **세대를 잇는 교배**: 부모의 종, 성향, 외형 특성, 육성 상태를 바탕으로 새로운 개체와 계보를 만듭니다. 목표는 다른 누구와도 다른 나만의 캐릭터를 얻는 것입니다.
- **모바일 동반 생활**: PC에서 키운 몬스터를 모바일로 가져와 위젯, 돌봄, 산책 등 가벼운 생활형 콘텐츠에 활용합니다.
- **몬스터별 ASMR**: 비·바람·숲·백색소음처럼 몬스터의 성격과 서식지에 어울리는 소리를 제공하고, 수면 중에도 재생할 수 있도록 설계합니다.

## 게임 구조

```text
PC (기준 기기)
  수집 → 방치 보상 → 육성 → 교배·부화 → 혈통 확정
                                      │
                         동기화 패키지 / QR 코드
                                      │
모바일 (동반 기기)
  위젯 · ASMR 재생 · 돌봄 · 생활형 상호작용
                                      │
                         선택적 돌봄 기록 전달
                                      │
PC에서 검증 후 반영
```

초기 버전에서는 **PC를 컬렉션과 교배의 기준 기기**로 둡니다. 모바일은 애착과 일상적 상호작용을 강화하지만, 희귀 개체·부화 결과·혈통의 최종 확정은 PC에서 처리합니다. 이 원칙은 오프라인 환경에서 기기 간 충돌과 데이터 복제를 줄이기 위한 것입니다.

## 데이터 동기화

이 프로젝트는 자체 계정 시스템이나 중앙 게임 서버에 의존하지 않는 것을 기본 원칙으로 합니다. 사용자는 자신이 소유한 동기화 데이터를 직접 보관하고 이동합니다.

### 컬렉션 동기화 패키지

PC는 컬렉션의 현재 상태를 하나의 동기화 패키지로 내보냅니다. 사용자는 이 파일을 클라우드 드라이브, 케이블, AirDrop, Quick Share 등 원하는 수단으로 모바일에 전달하고, 모바일 앱에서 가져옵니다.

패키지에는 다음 정보만 담습니다.

- 데이터 형식 버전, 프로필 식별자, 수정 번호 및 내보낸 시각
- 보유 몬스터와 성장·친밀도·장착 상태
- 혈통과 교배에 필요한 유전 정보
- 손상 여부를 확인하기 위한 무결성 값

개인정보, 키보드 입력 내용, 마우스 입력 내용, 사용 기록은 동기화 파일에 저장하거나 외부로 전송하지 않습니다. ASMR 원본 음원도 파일에 포함하지 않고 `soundId`만 보관합니다. 각 기기는 동일한 음원 리소스를 앱에 포함하거나 별도의 정식 다운로드로 준비합니다.

### 시드 코드와 교배 코드

시드 코드는 텍스트 또는 QR 코드로 전달할 수 있는 짧은 데이터 표현입니다.

- **개체 시드 코드**: 특정 몬스터의 외형·성향·유전 규칙을 재현하거나 기념 보관할 때 사용합니다.
- **교배 초대 코드**: 선택한 두 개체 또는 교배 후보의 정보를 다른 기기로 전달할 때 사용합니다.
- **프로필 QR 코드**: 작은 컬렉션이나 빠른 기기 이동에 사용할 수 있습니다. 컬렉션과 계보가 커질수록 파일 패키지를 권장합니다.

서버 없는 구조에서 시드 코드는 데이터 전달과 재현 수단이며, 완전한 소유권 증명이나 복제 방지 수단은 아닙니다. 같은 코드를 반복으로 가져오거나 교배 직전 데이터를 복사하는 행위까지 완전히 막으려면 서버 기반 검증이 필요합니다. 본 프로젝트는 경쟁보다 개인의 계보와 애착에 가치를 두는 방향을 우선합니다.

## 교배와 계보

교배는 부모의 특성을 단순히 섞는 기능이 아니라, 세대를 거치며 사용자의 선택이 쌓이는 수집 시스템입니다.

- 부모 종과 외형 특성에서 자손의 기본 형태를 결정합니다.
- 성향, 친밀도, 성장 환경, 돌봄 상태를 자손의 기질 또는 희귀 특성에 반영합니다.
- 모든 개체는 부모·세대·탄생 정보를 가진 계보로 연결됩니다.
- 동일한 교배라도 규칙 버전과 시드에 따라 결과를 재현할 수 있어야 합니다.

기존 육성 게임에서 영감을 얻되, 캐릭터·명칭·시각 디자인·구체적인 게임 규칙을 모방하지 않고 독자적인 몬스터와 시스템을 설계합니다.

## ASMR 설계 원칙

- 몬스터의 생태, 성격, 서식지와 연결되는 고유한 사운드 콘셉트를 만듭니다.
- 수면을 방해하지 않도록 부드러운 반복, 자연스러운 전환, 개별 볼륨 조절을 지원합니다.
- 장시간 재생을 위한 타이머, 반복 재생, 화면이 꺼진 상태의 재생 여부는 모바일 플랫폼 정책에 맞춰 결정합니다.
- 사용 권한이 명확한 자체 제작 또는 정식 라이선스 음원만 사용합니다.

## 데스크톱 입력 반응과 개인정보

데스크톱 앱은 전역 키보드·마우스 입력을 몬스터의 시각적 반응을 표시하는 용도로만 사용합니다. 키 입력의 내용이나 개인 정보를 기록하거나 외부로 전송하지 않습니다.

- **Windows**: 일반적으로 별도 권한 없이 동작합니다. 일부 보안 프로그램 또는 관리자 권한 앱의 입력은 감지하지 못할 수 있습니다.
- **macOS**: 전역 입력 반응을 사용하려면 운영체제의 **접근성(Accessibility)** 권한이 필요합니다. 앱은 권한의 목적과 사용 범위를 명확히 안내해야 합니다.

## 현재 기술 방향

| 영역 | 방향 | 상태 |
| --- | --- | --- |
| PC 앱 | Tauri 2 + React + TypeScript + Rust | 현재 프로젝트에 구성됨 |
| PC 지원 OS | Windows, macOS | 목표 |
| 로컬 데이터 | 로컬 저장소 또는 SQLite | 검토 중 |
| 동기화 규격 | 버전·수정 번호·무결성 값을 포함한 오프라인 패키지 | 설계 예정 |
| 모바일 앱 | Android/iOS 대상, 구현 기술 미정 | 결정 필요 |
| 위젯·백그라운드 ASMR | 각 모바일 OS 정책에 맞춰 구현 | 조사 필요 |

## 개발 단계

1. PC 입력 반응형 몬스터 표시와 사용자 리소스 세트(`idle`, `active`, 선택 `active_alt`)를 완성합니다.
2. PC의 수집·방치 보상·육성 데이터 모델을 정의합니다.
3. 몬스터 개체, 유전 정보, 혈통, 교배 규칙을 설계하고 로컬 저장합니다.
4. 동기화 패키지와 개체/교배 시드 코드 규격을 정의합니다.
5. 모바일 동반 앱과 위젯을 구현하고, PC 컬렉션 가져오기를 지원합니다.
6. 모바일 돌봄 기록의 PC 반영 정책과 충돌 처리 규칙을 추가합니다.
7. ASMR 라이브러리, 수면 재생 UX, 권한·배터리 정책을 검증합니다.

## 결정이 필요한 항목

- 모바일의 첫 지원 범위: Android 우선, iOS 우선, 또는 동시 지원
- 동기화의 기본 경험: 파일 선택, 개인 클라우드 폴더, QR 코드 중 무엇을 첫 화면에 둘지
- 모바일에서 PC로 되돌릴 수 있는 데이터의 범위: 친밀도만, 생활 기록, 꾸미기, 기타
- 교배 방식: 단일 기기 내 교배부터 시작할지, 코드 기반 교배 후보 교환도 초기 버전에 넣을지
- ASMR의 첫 콘텐츠 수와 음원 제작·라이선스 계획
- 프로젝트의 최종 이름과 라이선스
