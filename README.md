# 클리커 장난감

키보드와 마우스 입력에 반응해 사용자가 지정한 이미지를 보여주는 가벼운 데스크톱 위젯입니다. Bongo Cat처럼 입력 순간에 이미지를 바꾸며, 입력 내용·횟수·개인정보는 기록하거나 외부로 전송하지 않습니다.

현재 버전은 **0.1.1**입니다.

## 주요 기능

- Windows와 macOS 지원을 목표로 하는 Tauri 기반 앱
- 전역 키보드·마우스 입력에 반응하는 이미지 전환
- 1~4개의 클리커를 동시에 표시
- 클리커 번호별 `idle`, `active`, 선택 `active_alt` 이미지 설정
- 길게 누르는 동안 활성 이미지 유지
- 투명 PNG/WebP를 포함한 사용자 이미지 지원
- 공통 이미지 크기 조절과 위젯 드래그 이동
- 항상 위에 표시되는 테두리 없는 위젯과 트레이 메뉴
- 여러 음원의 무작위 재생 및 공통 사운드 켜기/끄기

## 이미지 리소스

클리커마다 아래 이미지 세트를 독립적으로 설정합니다.

| 슬롯 | 필수 | 표시 시점 |
| --- | --- | --- |
| `idle` | 권장 | 입력이 없을 때 |
| `active` | 권장 | 키보드 또는 마우스를 누르는 동안 |
| `active_alt` | 선택 | 입력마다 `active`와 번갈아 표시 |

설정 창에서 **클리커 추가**를 누르면 최대 4개까지 늘릴 수 있습니다. 3~4개는 2×2 형태로 표시됩니다. 기존 단일 클리커 설정은 자동으로 클리커 1로 이전됩니다.

## 사용 방법

1. 앱을 실행합니다. 이미지가 설정되지 않았다면 설정 창이 자동으로 열립니다.
2. 각 `클리커 1~4` 카드에서 기본·입력·보조 이미지를 선택합니다.
3. 필요하면 이미지 크기를 조정하고, 위젯 이미지를 드래그해 원하는 화면 위치로 옮깁니다.
4. 숨기기, 설정 열기, 종료는 트레이 아이콘의 오른쪽 클릭 메뉴에서 사용합니다.

이미지를 다시 선택하면 새 파일을 즉시 표시합니다. 기존 이미지 파일이 캐시되어 남지 않도록 새 리소스 경로를 사용합니다.

## 사운드

- MP3, WAV, M4A, AAC, OGG 파일을 추가할 수 있습니다.
- 입력이 시작될 때 등록된 음원 중 하나를 무작위로 한 번 재생합니다.
- 여러 클리커는 하나의 음원 목록과 사운드 켜기/끄기 설정을 공유합니다.
- 음원은 파일당 20MB, 총 100MB까지 등록할 수 있습니다.

## 권한과 개인정보

- **Windows**: 일반적으로 별도 권한 없이 동작합니다. 관리자 권한 앱 또는 일부 보안 프로그램의 입력은 감지하지 못할 수 있습니다.
- **macOS**: 전역 입력 감지를 위해 시스템 설정의 **접근성(Accessibility)** 권한이 필요합니다.

입력 정보는 이미지·사운드 효과 표시만을 위해 사용하며 저장하거나 네트워크로 전송하지 않습니다.

## 빌드와 배포

### Windows

```powershell
npm ci
npm run tauri -- build --bundles nsis
```

생성 위치:

```text
src-tauri/target/release/bundle/nsis/클리커 장난감_0.1.1_x64-setup.exe
```

### macOS

Windows에서는 macOS DMG를 직접 생성할 수 없습니다. GitHub Actions 워크플로 [macos-dmg.yml](.github/workflows/macos-dmg.yml)은 Apple Silicon과 Intel Mac용 DMG를 각각 빌드합니다.

1. 프로젝트를 GitHub 저장소에 푸시합니다.
2. GitHub 저장소의 **Actions → macOS DMG 빌드 → Run workflow**를 선택합니다.
3. 완료된 실행 화면의 **Artifacts**에서 원하는 Mac용 DMG를 다운로드합니다.

비공개 저장소의 Artifacts는 저장소 접근 권한이 있는 사용자만 내려받을 수 있습니다. 배포할 DMG만 OneDrive·Google Drive 등의 공유 링크로 전달하는 방식을 권장합니다.
